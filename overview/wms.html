WMS 한눈에보기

세원 WMS API — 개발 현황 요약

총 4개 API 개발 완료. 출고 주문 조회 / 반품 신청 / 재고현황 리스트 / 재고현황 상세.
수량·물류 흐름 데이터 확보 완료. 금액 데이터는 ERP에서 별도 확보.

1. 출고 주문 조회 (getOrderInfo) 개발 완료

출고 건 단건/기간 조회. 온/오프라인 구분. 반품 접수 정보 포함.

BILL_NO BILL_DATE STATUS ORDER_NO COMP_CODE COMP_NAME SELLIC_ID STYLE_CODE SKU COLOR SIZE SHIPPED_QTY TRACKING_NO RETURN_TRACKING_NO RETURN_COLLECTED ACTION
조회 방식최대 기간필터
SINGLE (단건) / PERIOD (기간)31일outType (온라인/오프라인/전체), compcode

2. 반품 신청 (sendOrderRtn) 개발 완료

우체국 전송 → WMS 반품 데이터 생성 → 차일디 웹훅 전송.

bill_no type reason_code items[].sellic_id items[].qty

3. 재고현황 리스트 (getStockTrack) 개발 완료

SKU 단위 수불 요약. 전일재고 + 기간 내 입출고 + 현재고.

SKU SKUCD BRAND_NAME SKU_NAME COLOR_CODE SIZE_CODE JUNIL_QTY IN_QTY IN_RTN_QTY OUT_QTY RTN_QTY JOJUNG_QTY NOW_QTY FIRST_DAN
조회 방식최대 기간필터
기간 조회 (startDate ~ endDate)3개월keyword (SKU/품번/바코드 부분일치)

4. 재고현황 상세 (getStockTrackDetail) 개발 완료

한 SKU의 기간 내 재고 이력. 행 단위 (입고/출고/반품/조정 등).

ITAG CONF_DATE CDATE CARGO_NAME COMP_NAME UNAME COMP_BILL_NO ONLINE_ORD_NO BOX_DELV_NO ACPT_MAN FIRST_QTY IN_QTY OUT_QTY RTN_QTY JO_QTY
조회 방식최대 기간필터
기간 + SKU 지정 (정확 일치)3개월sku (필수)

WMS에서 확보할 수 없는 것

아래는 WMS에서 제공하지 않아 ERP에서 별도 확보해야 하는 데이터 :

  • 금액 계열 — 실판가, 원가 (사전/사후), TAG가, FOB단가
  • 발주 정보 — 발주번호, 발주일, 발주확정일, 납기일, 발주 상태
  • 상품 속성 — 카테고리, 시즌, 성별, 소재, 썸네일
  • 주문 금액 — 실판매금액, 최초판매가, 현판매가
