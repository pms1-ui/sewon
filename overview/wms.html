1. 출고 주문 조회 (getOrderInfo) 개발 완료

출고 건 단건/기간 조회. 온/오프라인 구분. 최대 31일. compcode 필터 가능.

1BILL_NO전표번호출고 묶음 식별
2BILL_DATE전표생성일출고일
3STATUS출고상태Y=완료
4CUSTOMER_NAME수령인명
5ORDER_NO온라인주문번호매출대사 핵심 키
6COMP_CODE판매처코드
7COMP_NAME판매처명
8SELLIC_ID셀릭번호품목 고유
9PRODUCT_NAME상품명
10STYLE_CODE품번
11SIZE사이즈
12COLOR색상코드
13COLOR_NAME색상명
14BARCODE바코드
15SKUSKU
16SHIPPED_QTY출고수량
17UNIT_PRICE단가대부분 0 → ERP 실판가로 대체
18TRACKING_NO출고운송장
19RETURN_TRACKING_NO반품운송장
20RETURN_COLLECTED반품회수여부Y/N
21ACTION반품접수구분반품/교환
22SELECTED_OPTION선택옵션
23PHONE_NUMBER수령인전화
24DELIVERY_MEMO출고메모

2. 반품 신청 (sendOrderRtn) 개발 완료

우체국 전송 → WMS 반품 데이터 생성 → 차일디 웹훅 전송.

#필드한글명설명
1bill_no전표번호필수
2type신청구분EXCHANGE/REFUND
3reason_code반품사유코드필수
4items[].sellic_id셀릭번호필수
5items[].qty반품수량최소 1

3. 재고현황 리스트 (getStockTrack) 개발 완료

SKU 단위 수불 요약. 최대 3개월. keyword 검색 가능.

9OUT_QTY출고수량

11JOJUNG_QTY재고조정
12NOW_QTY현재고전일+입고-입고반품-출고+반품+조정
13BAR_CODE바코드
14SKUSKU품번+컬러+사이즈
15SKU_COLOR컬러명한글
16SKU_SIZE사이즈명
17FIRST_DAN최초가정가
