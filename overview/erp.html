ERP 한눈에보기

세원 ERP — 개발 요청 현황 요약

4개 테이블 수신 필요. 상품 마스터 / 판매현황 / 발주 정보 / 입고현황.
WMS에서 확보한 수량 데이터에 금액·속성·상태 정보를 결합하기 위함.
동기화 방식 : 수정일자 기준 정렬 조회하여 변경분 업데이트.

A. 상품 마스터 (고정 테이블) 개발 필요

출처 : 상품정보등록 화면 | 기준 키 : STYLE NO | 일 1회 전체 수신

STYLE_NO PRODUCT_NAME BRAND_CODE YEAR SEASON CATEGORY_L CATEGORY_S GENDER MATERIAL ORIGIN PLAN_TYPE BATCH_NO COLOR_SIZE_QTY THUMBNAIL TAG_PRICE FIRST_PRICE PRE_COST POST_COST FOB_PRICE EXCHANGE_RATE PRICE_CONFIRM_DATE SALE_START_DATE

SALE_START_DATE (판매예정일) = 신규 필드 추가 요청. 발주확정 전환 시 필수 입력.

B. 판매현황 (기간제 테이블) 개발 필요

출처 : 판매현황 화면 | 기준 키 : 온라인주문번호 + 품번+색상+사이즈 | 일 1회 전일 수신

SALE_DATE SHOP_CODE SHOP_NAME SALE_NO SALE_SEQ WORK_TYPE RETURN_TYPE PURCHASE_TYPE ONLINE_ORDER_NO ITEM_ORDER_NO SELLIC_ID STYLE_NO PRODUCT_NAME COLOR_CODE SIZE_CODE FIRST_SALE_PRICE CURRENT_PRICE SALE_QTY ACTUAL_SALE_AMT

ITEM_ORDER_NO (품목별주문번호) = 신규 필드 추가 요청. 셀릭 쪽에서 생성·전달 필요.

C. 발주 정보 (기간제 테이블) 개발 필요

출처 : 상품정보등록 + 발주현황 | 기준 키 : STYLE NO + 차수 | 일 1회 전체 수신

ORDER_ID STYLE_NO ORDER_DATE CONFIRM_DATE DUE_DATE COMPLETE_DATE ORDER_QTY ORDER_STATUS SUPPLIER PURCHASE_TYPE BATCH_NO STOCK_CLOSE_YN SALE_CLOSE_YN

ORDER_STATUS : 발주미정 → 발주확정 → 진행중 → 입고완료 → 종료

D. 입고현황 (기간제 테이블) 개발 필요

출처 : 입고현황 화면 | 기준 키 : 품번+색상+차수 | WMS와 건별 조인 불가 — 금액/원가 분석 독립 활용

STOCK_IN_DATE STOCK_IN_NO SUPPLIER_NAME WORK_TYPE FIRST_IN_DATE STYLE_NO PRODUCT_NAME BATCH_NO COLOR_CODE PROGRESS_TYPE PURCHASE_TYPE FIRST_SALE_PRICE IN_UNIT_PRICE POINT_AMT PRE_COST PRE_COST_AMT IN_AMT FIRST_SALE_AMT EXPECTED_QTY TOTAL_QTY SIZE_QTY

입고현황에 시점별 원가 스냅샷 포함 — 원가 변동 추적 가능.

신규 개발 요청 항목

#항목상태
1발주번호 채번 규칙 개발요청 중
2판매예정일(발매개시예정일) 필드 추가 + validation신규
3품목별주문번호 키 추가 (ERP/WMS)신규
4엑셀업로드 양식 수정 (라인시트 활용)요청 중
